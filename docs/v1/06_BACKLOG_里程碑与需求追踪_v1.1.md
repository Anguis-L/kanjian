# Kanjian 里程碑、工作包与需求追踪 v1.1

- 版本：v1.1｜日期：2026-11-03｜状态：开发评审修订稿
- 上游：PRD v1.1、ARCH v1.1、SDD v1.1、TDD v1.1、TEST v1.1
- 修订依据：`REVIEW_v1.md`；变更明细见 00 §9「修订记录」
- 工期为单人/小团队规划参考，不是交付承诺；以 Gate 通过为准，而非日期到点即发布。

## 1. 里程碑

| 里程碑 | 参考周期 | 主要交付 | 退出条件 |
|---|---:|---|---|
| M0 需求与合规冻结 | 1–2 周 | 本文档集、许可证骨架、威胁模型、评测计划 | 需求评审通过；无隐藏导航目标；数据与授权边界明确 |
| M1 垂直切片 | 2–3 周 | Android 单帧询问、一个 VLM Provider、本地TTS、结构化输出与策略过滤、**首次说明与默认关闭状态（WP-G）** | G0/G1；主动询问闭环；无原图落盘；**未完成说明前不采集** |
| M2 自动观察与可靠性 | 3–4 周 | 采样、帧差触发、单飞/取消/超时、去重/冷却、降级与历史、**预算与限流（WP-H）** | 静止场景不重复上云；迟到结果隔离；队列稳定；**预算超限可感知暂停** |
| M3 阅读与无障碍 | 2–3 周 | OCR 模式、TalkBack 全流程、配置与数据清除、**音频焦点默认策略（WP-I）** | 核心 TalkBack 任务无阻断；G2 |
| M4 性能与共创试点 | 3–4 周 | 真机基线、成本报告、准确性数据集、受控共创 | 达到 PRD 工程目标或公开偏差；**性能报告含失败率/超时率**；G3 |
| M5 公开 Beta | 2 周 | 发布包、文档、第三方清单、支持与回滚机制 | G4；发布阻断项清零；**发行包端点扫描通过** |

## 2. 工作包

### WP-A 项目治理

- 建仓库、分支保护、CI、依赖锁定与文件级许可证清单。
- 完成 LICENSE、NOTICE、SAFETY、PRIVACY、SECURITY、CONTRIBUTING、CLA、TRADEMARK。
- 建需求 ID、设计 ID、测试 ID 的 PR 关联规则。
- 输出：可构建空壳 + 合规骨架，而不是先上传无许可证明代码。

### WP-B Android 帧与交互

- CameraX 生命周期、最新帧、压缩、权限和后台行为。
- 主动询问/阅读/自动观察三种模式与 TalkBack。
- 输出：FrameSource、CaptureService、基础 UI。

### WP-C 推理与网关

- SceneRequest/Result Schema、Scene API、Provider 接口、一个参考实现。
- 错误码、超时、限流、能力与用量记录。
- 输出：Fake Provider + 真实 Provider，可通过相同契约测试。

### WP-D 调度与语音

- TriggerEngine、InferenceCoordinator、SceneFingerprint、SpeechScheduler。
- 本地 TTS、打断、去重、冷却、停止与降级。
- 输出：可用 FakeClock 全面回放的调度模块。

### WP-E 策略与隐私

- SceneNormalizer、OutputPolicyEngine、OCR 不可信文字隔离。
- 本地历史、全部清除、网络抓包验证、日志审查。
- 输出：安全策略版本与对抗样本回放报告。

### WP-F 评测与发布

- 真机性能/功耗/成本基线、授权评测集、视障共创、缺陷闭环。
- 发布说明必须列明未完成验证的场景与已知限制。

## 3. 角色配置建议

| 角色 | 投入重点 |
|---|---|
| Android 工程 | 相机、调度、语音、本地存储、无障碍 |
| 后端/模型工程 | 网关、Provider、结构化输出、成本与自托管 |
| 算法/评测 | 触发、数据、幻觉与方位评测、性能调优 |
| 无障碍设计/研究 | 信息架构、TalkBack、视障共创与伦理 |
| QA | 契约、故障注入、真机矩阵、发布 Gate |
| 法律/合规（按需评审） | CLA、第三方许可、隐私文本、试点协议 |

公益项目可一人兼多角，但**安全策略作者与最终验收者不宜完全同一人自测自签**。

## 5. 风险登记

| 风险 | 早期信号 | 缓解 | 责任角色 |
|---|---|---|---|
| 自动模式云成本失控 | 触发率接近100%、旧请求堆积 | 默认关闭自动模式（FR-CFG-002）；显示成本；硬并发与预算上限（NFR-COST-002/003） | 后端+产品 |
| 描述过长、信息负担高 | 用户频繁打断、重复播报 | 短文本、冷却、共创调参 | 无障碍+算法 |
| 模型幻觉被当成事实 | 确定语气、无依据物体 | 结构化不确定、策略过滤、明确局限 | 算法+QA |
| 功能悄悄滑向导航 | 需求出现“引导/绕行/安全”词 | 非目标评审；PRD变更需重新风险审查 | 全体 |
| 第三方许可污染 | 权重/数据来源不明 | 文件级清单、CI阻断、CLA | 维护者 |
| 用户形成过度依赖 | 测试者抛弃既有辅助工具 | 明示边界、观察误用、限制公开宣传 | 研究+产品 |
| 真机性能不达标 | 高温降频、P95超标 | 降采样、减少自动触发、Provider替换，不延长等待掩盖 | Android+后端 |
| **公益项目被默认端点拖垮** | 出现维护者付费的公共端点 | ADR-07 禁止公开发行含默认端点；用户自配 | 维护者+后端 |
| **首次说明被跳过导致误用** | 用户不知数据离端 | FR-ONB-001 强制确认；不可仅小字链接 | 无障碍+产品 |
| **TalkBack 与自播报争抢音频焦点** | 播报被吞或重复 | FR-ACC-003 默认不请求独占焦点、检测到 TalkBack 让行 | Android+无障碍 |
| **P95 与超时阈值混淆导致指标失真** | 报告混入超时样本 | PRD §7.1、TEST §4.2 强制口径 | QA |
