## 二、硬伤清单与处理结果

### P-01 超时阈值与 P95 目标数值冲突 —— 已修复

**问题**：PRD `NFR-PERF-001` 要求 P95 ≤ 4.0s，TDD §12 的"请求总超时"恰为 4s。等于超时阈值就是性能目标本身，任何一次超时都直接击穿指标，且不留工程余量；同时"超时样本是否计入 P95"未定义，报告口径可被任意解释。

**修复**（R-01）：
- PRD §7 新增 §7.1「延迟口径与超时预算」：`T_budget = P95目标 + 缓冲`，`4.0 + 2.0 = 6.0s`。
- 明确 **P95 只在成功样本上统计**，超时/失败样本单列失败率与超时率。
- 明确禁止用调长超时"达标"，与 TDD §12、06 风险登记保持一致。
- TDD 新增 §12.1 同步该预算，并改写 §12 初始值（4s → 6s）。
- TEST §4.2 新增口径强制要求，缺失败率/超时率的报告判为无效。
- TEST §8 新增对应发布阻断项。

**影响**：TDD §12 开发初始值由 4s 改为 6s。实现时 `T_budget` 与 P95 是两个不同变量，不得复用同一常量。

### P-02 需求 ID 覆盖有洞 —— 已修复

**问题**：PRD §5.1 的 P0 清单有 12 项能力，但其中至少 4 类没有 FR 编号：

| 第 12 项：首次使用安全/隐私说明 | 无 | 同上 |
| §10 埋点与成本需求 | 无 | 同上 |

这直接违反 00 §7「所有 PRD 需求均能映射到 SDD/TDD 与测试用例」。

**修复**（R-02）：新增以下需求 ID 并同步进 06 §4 追踪矩阵：

| 新增 ID | 需求 | 主要测试 |
|---|---|---|
| FR-VLM-005 | `speech_candidate` 与 `text_regions` 不得绕过策略 | TEST-SAF-005/008 |
| FR-ACC-003 | 音频焦点默认策略 | TEST-ACC-003/004 |
| FR-CFG-002 | 自动观察默认关闭 | TEST-CFG-001/002 |
| FR-CFG-003 | 配置变更即时失效在途任务 | TEST-CFG-003 |
| FR-ONB-001/002 | 首次安全/隐私说明 | TEST-ONB-001/002 |

### P-03 默认端点自相矛盾 —— 已修复

**问题**：ARCH §9.1 写"官方 App 连接项目网关"，§11 又写"不提供一个让普通用户无感知消耗维护者 API 额度的公开默认端点"。两句话未定义 MVP 的默认配置，导致公益项目最关键的"成本由谁承担"无答案，且实现时无从选择。

**修复**（R-03）：新增 **ADR-07：MVP 不提供维护者付费的公开默认端点**，状态"接受"。
- 公开发行版云端能力初始为"未配置"，用户须显式配置自托管网关或自有 API 才能启用。
- §9.1 的表述限定为"受控部署（内部开发/受邀试点）"。
- 同步修改 §11 部署形态与 §12 架构验收条件（新增"发行包不含预置端点"）。
- 同步落地为 FR-DEF-001 的可测部分、TEST-DEF-001/002、CI 门槛第 7 条、发布阻断项。

### P-04 预算上限没有验收落点 —— 已修复

**问题**：06 §5 风险登记的缓解措施写了"硬并发与预算上限"，但 PRD 只有 `NFR-COST-001`（可观测），没有任何"超预算即停"的需求、指标与测试。即风险被识别，但未转化为可验收约束。

**修复**（R-04）：
- PRD 新增 `NFR-COST-002`（预算上限，达阈值暂停自动模式并语音告知）与 `NFR-COST-003`（网关并发硬上限，快速 `RATE_LIMITED`）。
- SDD 新增 `BudgetGuard` 组件、状态机 `BudgetHalted` 状态、不变量 8、错误矩阵两行。
- TDD 新增 §13.1「预算与限流」，定义两个计数维度、重置规则、禁止静默消耗。
- TEST 新增 §3.5.1 五个用例（TEST-COST-001~005），含"杀进程重启后累计不丢失"这类绕过防护。
- 06 风险登记与里程碑 M2 同步。

### P-05 调研锚点缺失 + `/docs` 路径未对齐 —— 已修复

**问题**：
1. 00 §8 引用了 `research/01~03` 三份调研，但工作区中不存在，导致需求依据不可核查。
2. 00 §6 治理基线要求 `/docs/v1/*`，而当前文档在 `Kanjian_开发策划文档_v1/v1/`，路径不一致，入库时易出现两个"权威版本"。

**修复**（R-05）：
- 00 §8 改为表格，逐份标注"工作区缺失，需补入或归档说明"，并加约束：调研锚点缺失期间不得以"见调研"代替可核查记录。
- 00 §6 明确 `docs/v1/` 为唯一正式入库路径，工作区副本目录名不作为仓库路径。
