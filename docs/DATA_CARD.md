## 评测数据集规则（ADR-14）

若建立评测集，必须满足：

1. **来源合法、用途明确、授权可追溯**；不默认收集真实用户出行视频。
2. **规模**：基线集 ≥300 张，覆盖 8 类场景（室内、室外静止、光照变化、遮挡、模糊、透明物体、小目标、文字/空场景），每类 ≥30。
3. **对抗集** ≥150 条，必含中英混合、空格拆字、否定句、括号藏建议、OCR 文本注入。通过标准是**播报放行数 = 0**，不是准确率阈值。
4. **划分**：按场景划分训练/调参/测试，避免相邻近重复帧泄漏。
5. **标注**：记录采集条件与标注者分歧；不把主观推测当唯一真值。
6. **发布前复核**：重新审查人脸、门牌、车牌、位置等信息。

## 已知的数据相关风险

- 真实场景图像极易包含**可识别的人脸、门牌、车牌**——这是禁用真实用户数据的核心理由
- 视障用户的第一人称视角可能暴露其居住环境与行动路线
- 共创测试中的语音反馈原话须匿名化，引用前再次取得许可

## 数据许可证

评测集原则上采用 **CC BY-SA 4.0**，并另附数据来源、授权与限制说明。任何未明确授权的数据不得入库。

## 变更记录

新增数据集或改变上述任一规则时，必须更新本文件并在 PR 中说明。
