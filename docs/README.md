## 读文档的顺序

如果你只有 5 分钟：读 [../SAFETY.md](../SAFETY.md) → 本文件 → 00 总纲的「已锁定的产品决策」。

如果你要改代码：读 03 SDD §8（输出策略四层）+ 04 TDD §9，再看 `kanjian/policy.py` 与 `tests/test_policy.py`。**改策略前必须理解为什么对抗集放行数要求为 0。**

## 版本策略

- `v1.0` 为冻结基线（不在本仓库，保留在开发工作区）
- `v1.1` 为当前评审修订版；**M0 签署后转为冻结基线**，此后新决策起 v1.2
- 任何决策必须形成新 ADR 或新版本，不得直接覆盖已冻结的基线
