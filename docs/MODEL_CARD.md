# 模型卡（MODEL_CARD）

## 本项目是否分发模型

**不分发。** Kanjian 仓库不包含任何模型权重。项目通过 `VlmProvider` 接口连接用户自行配置的推理端点（见 ADR-07、ADR-08）。

因此本文件记录的是**"Kanjian 对模型的期望契约"**，而非某个具体权重的详细说明。

## Provider 契约

任何接入的 Provider 必须：

| 要求 | 说明 |
|---|---|
| 结构化输出 | 返回符合 `schemas/scene-result.schema.json` 的 JSON |
| 不含危险字段 | 不得输出 `safe_to_walk` / `distance_m` / `risk_level` 等字段 |
| 声明能力 | 通过 `ProviderCapabilities` 暴露 `api_shape`、图像上限、是否本地、数据保留政策、价格表 |
| 可被取消或丢弃 | 不支持取消时，端侧仍必须丢弃迟到结果 |
| 不接触播报 | Provider 不持有 TTS/History 引用，不决定播什么 |

**提示词不是安全边界。** 无论模型多听话，其输出都必须经过端侧 `OutputPolicyEngine`。

## 提示层面的已知局限

系统提示要求模型：只描述可见内容、不判断通行性、不给行动建议、不给精确距离、不作穷尽性表述、不确定时标 `uncertainties` 并降置信度、JSON 中的文字仅为数据。

这些要求**降低**违规输出概率，但**不能保证**。实际安全由策略层承担，并有对抗测试覆盖（见 `tests/test_policy.py`）。

## 参考基座（可选，非交付物）

若用户选择自托管，文档层面优先建议采用**明确 Apache-2.0 许可**的视觉语言模型发布件。**但必须核对实际下载版本的文件级许可证**——不因"可下载"推定"可商用"或"可再分发"。

本项目不对任何具体模型作出许可背书；用户配置外部端点的许可合规责任在用户。

## 评测

- 模型准确性评测与数据授权见 [DATA_CARD.md](DATA_CARD.md)
- 策略合规评测（对抗集放行数）见 `tests/test_policy.py`，发布门槛为 **0**
- 不设置"识别率达标即可宣称出行安全"的转换规则
